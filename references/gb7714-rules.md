# GB/T 7714-2015 参考文献著录规则速查（顺序编码制）

本文件是 `reference-woodpecker` 技能的规则依据，供检查脚本与 LLM 复核"存疑"条目时查阅。

> 标准全称：《信息与文献 参考文献著录规则》（GB/T 7714-2015），2015-05-15 发布，2015-12-01 实施。
> 国内高校论文普遍采用其**顺序编码制**（按正文引用先后顺序编号 [1][2][3]…）。本技能只检查顺序编码制。

## 1. 通用著录结构

```
主要责任者. 题名: 其他题名信息[文献类型标识/载体类型标识]. 其他责任者. 版本项.
出版地: 出版者, 出版年: 引文页码[引用日期]. 获取和访问路径. 数字对象标识符.
```

- 每条以 `[序号]` 开头，序号为阿拉伯数字，从 1 起连续编号。
- 著录用标点为**半角**（`.` `,` `:` `//` `-` 等），后跟一个空格；即使条目是中文文献，著录标点也不用全角。
- 条目以 `.` 结尾。
- 题名照录原文，题名内部的标点不作为著录标点检查。

## 2. 文献类型标识（标准附录 B）

| 标识 | 类型 | 标识 | 类型 |
|---|---|---|---|
| M | 普通图书 | S | 标准 |
| C | 会议录 | P | 专利 |
| G | 汇编 | A | 档案 |
| N | 报纸 | CM | 舆图 |
| J | 期刊 | DS | 数据集 |
| D | 学位论文 | DB | 数据库 |
| R | 报告 | CP | 计算机程序 |
| EB | 电子公告 | | |

电子资源载体标识：`OL`（联机网络）、`MT`（磁带）、`DK`（磁盘）、`CD`（光盘）。
常见组合：`[J/OL]` `[M/OL]` `[EB/OL]` `[DB/OL]` `[N/OL]`。

## 3. 各类型著录模板与示例

### 3.1 期刊 [J]
```
[序号] 作者. 题名[J]. 刊名, 出版年, 卷(期): 起止页码.
[序号] 作者. 题名[J]. 刊名, 出版年(期): 起止页码.        （无卷号）
```
示例：`[1] 张伟, 李明. 基于深度学习的图像识别方法研究[J]. 计算机学报, 2020, 43(5): 101-110.`
必备：作者、题名、刊名、出版年。缺页码降级为警告（部分刊物允许在线优先发表无页码）。

### 3.2 专著 [M]
```
[序号] 作者. 书名[M]. 版本(第1版不著录). 出版地: 出版者, 出版年: 引文页码.
```
示例：`[2] 王芳. 数据结构与算法分析[M]. 北京: 清华大学出版社, 2019: 45-60.`
必备：作者、书名、出版地、出版者、出版年。

### 3.3 学位论文 [D]
```
[序号] 作者. 题名[D]. 保存地: 保存单位, 年份.
```
示例：`[3] 刘洋. 高并发系统架构关键技术研究[D]. 北京: 北京航空航天大学, 2021.`
必备：作者、题名、保存单位、年份。

### 3.4 会议论文集及析出文献 [C]
```
[序号] 作者. 题名[C]//论文集名. 出版地: 出版者, 出版年: 页码.
```
示例：`[4] 陈晨, 赵磊. 分布式一致性协议研究进展[C]//第十八届全国计算机学术年会论文集. 上海: 华东师范大学出版社, 2018: 12-18.`
析出文献必须含 `//` 引出文集名。

### 3.5 标准 [S]
```
[序号] 标准编号, 标准名称[S]. 出版地: 出版者, 出版年.
或 [序号] 责任者. 标准名称: 标准编号[S]. 出版地: 出版者, 出版年.
```
示例：`[5] 信息与文献 参考文献著录规则: GB/T 7714-2015[S]. 北京: 中国标准出版社, 2015.`

### 3.6 报纸 [N]
```
[序号] 作者. 题名[N]. 报纸名, 出版日期(版次).
```
示例：`[6] 李红. 人工智能教育应用的现实困境与路径[N]. 中国教育报, 2021-06-15(8).`
必备：报纸名、出版日期（YYYY-MM-DD）。

### 3.7 电子资源 [EB/OL] 及 OL 系列
```
[序号] 作者. 题名[EB/OL]. (更新或修改日期)[引用日期]. 获取和访问路径.
```
示例：`[7] 教育部. 关于印发《高等学校数字校园建设规范》的通知[EB/OL]. (2021-03-15)[2021-05-06]. http://www.moe.gov.cn/xxgk.`
必备：**获取和访问路径（URL）**。缺 URL 属于错误；缺引用日期 `[YYYY-MM-DD]` 属于警告。

### 3.8 报告 [R]
```
[序号] 作者. 题名[R]. 出版地: 出版者, 出版年.
```
示例：`[8] 周洁. 企业数字化转型研究报告[R]. 北京: 某咨询公司, 2020.`

### 3.9 专利 [P]
```
[序号] 专利申请者或所有者. 专利题名: 专利号[P]. 公告日期或公开日期.
```
示例：`[9] 吴刚. 一种基于区块链的数据共享方法: CN110123456A[P]. 2019-08-16.`
必备：专利号（如 `CN…A/B`）。

## 4. 标点与格式细则（脚本检查点）

| 检查点 | 规范要求 | 违规示例 |
|---|---|---|
| 序号 | 半角方括号+阿拉伯数字，连续 | `[01]`、`［１］`、跳号、重复 |
| 类型标识 | 题名后紧跟 `[J]` 等大写标识 | 缺标识、`[j]` 小写、`[X]` 未知 |
| 条目结尾 | 半角句点 `.` | 以 `。` 结尾、无结尾句点 |
| 著录标点 | 半角标点+空格 | 出版项区出现 `，` `：` `。` `、` |
| 页码 | `数字-数字`，半字线 | `101~110`、`101—110`、`101、110` |
| 年份 | 4 位阿拉伯数字 | `2020年`、`(2020年)`、两位年份 |
| 电子资源 | 必须含 URL | 缺 URL、URL 拼写无法识别 |
| 作者 | 作者间 `, ` 分隔 | 顿号 `、` 分隔 |
| 顺序编码制 | 按正文首次引用顺序编号；列表条目应被正文引用 | 正文引用 `[20]` 不在列表中；列表条目从未被引用 |

## 5. 脚本不判定、需人工/LLM 复核的项

- 作者是否满 3 人应加"等/et al."：需要外部知识判断真实作者数，脚本无法确定性判定。
- 文献内容真实性、是否存在该文献：本技能不联网核验。
- 题名内部标点是否与原文一致：题名照录，不做改写判断。
- 著者-出版年制（无 [序号] 列表）：本技能范围外，检测到会明确提示不适用。
- 出版项区含中文书名号《》等：可能是题名照录内容，标记为"存疑"而非直接判错。

## 6. 检查结果分级

- **ERROR（错误）**：违反标准明确规则，提交前必须修改。
- **WARN（警告）**：常见不规范，建议修改（如缺页码、缺空格、条目未被正文引用）。
- **INFO（存疑）**：规则无法确定性判定，列出位置请作者或 LLM 人工复核。
- **PASS**：未发现问题。
