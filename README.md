# 引文啄木鸟 · 参考文献格式自检官（reference-woodpecker）

面向高校学生的 **GB/T 7714-2015 参考文献格式自查 TeleAgent Skill**。论文提交前用它逐条"啄"出参考文献格式问题，输出可复核的自检报告。

## 解决什么问题

写毕业论文 / 课程论文 / 实验报告时，参考文献格式规则繁多——期刊[J]、专著[M]、学位论文[D]、会议[C]、标准[S]、报纸[N]、报告[R]、专利[P]、电子资源[EB/OL]各有字段与标点要求，肉眼逐条核对费时且易漏，提交后被退回返工。

本工具用**确定性规则引擎**（正则 + 结构解析）逐条检查，每个结论可复核、可溯源，不靠"感觉"判断。

## 快速开始

```bash
# 检查含正文的完整文档（自动定位"参考文献"节）
python scripts/check_refs.py 论文.docx --report 自检报告.md --json 结果.json

# 仅有参考文献列表
python scripts/check_refs.py refs.txt --refs-only --report 报告.md

# stdin 输入
type refs.txt | python scripts/check_refs.py -
```

> 纯 Python 标准库实现，零第三方依赖；全部检查在本地完成，不上传任何数据。

## 输入与输出

- **输入**：粘贴的参考文献文本，或 `.txt` / `.md` / `.docx` 文件路径（脚本自动提取文本；旧版 `.doc` 需先另存）
- **输出**：Markdown 自检报告（总体结论 → 问题汇总表 → 逐条明细 → 未覆盖项声明），可选 JSON 机器可读结果
- **分级**：ERROR（违反标准，必须改）/ WARN（建议改）/ INFO（存疑，人工复核）/ PASS

## 检查项覆盖

| 类别 | 检查内容 |
|---|---|
| 编号 | 连续性、重复、跳号、起始号、全角序号/全角数字 |
| 类型标识 | 缺失、小写（[j]）、未知标识（[X]）、OL 载体组合 |
| 分类型字段 | 期刊出版年与页码、专著出版地/出版者、学位论文保存单位、报纸日期、报告年份、专利号、标准编号 |
| 著录标点 | 中文句号、顿号分隔作者、全角标点、页码分隔符（~ — 、） |
| 正文引用对应 | 引用不存在条目、条目未被引用、首次引用顺序（顺序编码制） |
| 其他 | 重复条目、条目未以句点结尾、题名与类型标识间空格 |

## 能力边界

- 仅支持**顺序编码制**（`[1] [2] [3]…` 编号）；著者-出版年制明确提示不适用
- 不联网核验文献真实性；不判断学术质量；不代改正文
- 作者"等/et al."规则、版式项（字体/页边距）需人工确认，报告末尾明确声明
- 无法确定性判定的项标记 INFO"存疑"，绝不虚构结论
